GoHost PMS Public API

Overview

RESTful API for third-party partners to integrate with GoHost Property Management System.

Base URL

  • Production: https://platform.gohost.vn/pms/api/public/v1

Authentication

All API requests require Bearer token authentication.

Token Format: {api_key}:{api_secret}

Example:

curl -H "Authorization: Bearer abc123xyz:secret456def" \
  https://platform.gohost.vn/pms/api/public/v1/properties

How to get API credentials:

  1. Login to GoHost PMS Admin panel
  2. Navigate to Settings > Integrations > Public API Keys
  3. Create a new API key with appropriate scopes
  4. Copy the API Key and API Secret
  5. Combine them as {api_key}:{api_secret} for Bearer token

Rate Limiting

  • Default: 60 requests per 5 minutes per API key
  • Custom limits available for enterprise partners

Response Format

All responses follow standard JSON format:

{
  "success": true,
  "data": {...}
}

Error Codes

CodeDescription
AUTH_001Missing or invalid Authorization header
AUTH_002Authentication failed
AUTH_003API key disabled
AUTH_004API key expired
SCOPE_001Insufficient permissions
RATE_001Rate limit exceeded
BOOKING_001Booking operation failed (400, or 500 for an unexpected error)
BOOKING_002Invalid service in Update Booking (rooms[].services)
BOOKING_ROOM_INVALID_STATUSBooking Rooms endpoints: the room (or booking) status does not allow the operation — body also has checkin_status, booking_status (422)
BOOKING_CHECKOUT_UNBALANCEDCheck-out Booking Room: the property requires full payment and the room balance is not zero (single-room booking: the booking balance) — body also has numeric balance (> 0 due, < 0 overpaid) (422)
INVOICE_NO_PRIMARY_GUESTUpdate Booking: invoice info sent but the booking has no primary guest (422)

Validation errors return HTTP 422 with errors (field → messages).

Scopes

  • properties:read - Read property, room type, rate plan data
  • bookings:read - Read booking data (including services used per room)
  • bookings:write - Create and update bookings: confirm, payments, cancel, online check-in, and per-room check-out / cancel / rate change (Booking Rooms)
